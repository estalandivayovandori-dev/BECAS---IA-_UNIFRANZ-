# BECAS IA — Prototipo académico

## Requisitos
- Python 3.9 o superior
- Conexión a internet para instalar dependencias (no se requiere API de IA)

## Instalación
1. Descarga y descomprime el archivo ZIP.
2. Abre una terminal dentro de la carpeta.
3. Ejecuta:
   pip install -r requirements.txt
4. Ejecuta:
   streamlit run app.py
5. Se abrirá la aplicación en el navegador.

## Contenido
- Panel general
- 120 expedientes ficticios
- Alertas demostrativas
- Bandeja de revisión humana
- Auditoría territorial
- Simulador de corrección
- Apartado de privacidad y metodología

## Importante
Todos los datos son inventados. Las alertas son reglas demostrativas, no una IA que verifica identidad ni consulta registros externos. Los pesos del puntaje son ilustrativos y no deben usarse para adjudicar becas reales.
